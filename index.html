Start with your calendar links.

You and your partner each do these steps for every source calendar.

☁ Get an iCloud calendar link
  1. On your iPhone, open Calendar → Calendars.
  2. Tap ⓘ beside a source calendar. Turn on Public Calendar, then tap Share Link → Copy.
  3. Paste that link below. Repeat for your partner’s calendars.
▣ Get an Outlook / Hotmail link
  1. Open Outlook Calendar in Safari. Use Request Desktop Website from Safari’s page menu if settings are hidden.
  2. Open Settings → Calendar → Shared calendars → Publish a calendar.
  3. Choose the calendar and the detail level you want to share, then Publish. Copy the ICS link, not the HTML link. Publishing may be unavailable on managed accounts.
Feed links are private information: anyone who has a published link can read the shared details. Only continue if both of you are comfortable with this. Don’t add your Family destination as a source — that would create a loop.

Give your family calendar a helper.

This last step puts the sync in the cloud, so your phone doesn’t need to stay on.

  1. In Calendar, confirm you can add an event to the shared Family calendar. Check its exact name below. Don’t publish this destination.
  2. Go to account.apple.com → Sign-In and Security → App-Specific Passwords. Create one named “Gather”. Apple requires two-factor authentication. Use this password, never your regular Apple password.
This page builds your settings on your device. It does not send your password to a server or save it in browser storage. Clear the settings after you copy them.
Finish in GitHub — step by step
  1. Sign in to GitHub in Safari. Use a private repository containing this project’s files, including its .github/workflows/sync.yml workflow. The project owner must upload these files first; this page alone cannot deploy the service.
  2. Open that repository’s Settings → Secrets and variables → Actions → New repository secret. If needed, request Safari’s desktop website.
  3. Name it FAMILY_SYNC_CONFIG. Paste the settings above as its value and save. Never paste them into a code file, issue, or chat.
  4. Open Actions → Family calendar sync → Run workflow. A green check means the run completed; open the run to read its result.
  5. Check the Family calendar for a copied appointment. Change its time in the source, run again after the feed refreshes, then delete it in the source and repeat. Confirm that only the copy disappears.
  6. Leave the workflow enabled for hourly runs. Schedules can be delayed. Keep paid Actions usage disabled to avoid charges; if your included allowance runs out, syncing stops until it resets.
Only appointments returned by the feeds can be copied. Recurring events and exceptions are preserved. Copies have no guest invitations or reminders. Unrelated Family events are left alone. To stop, disable this workflow in Actions and revoke the app-specific password; existing copies remain.
